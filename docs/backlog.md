# 開発バックログ

## MVP：編集の流れを確かめる

1. 記録カードの登録・編集・削除とローカル保存。
2. カードの種別、テーマ、日付、根拠状態、出典の表示。
3. テーマ別カード一覧と、起承転結への手動配置。
4. Markdown記事のプレビューと書き出し。
5. JSONの書き出し・読み込み。
6. 出典のない記述、未確認情報、未配置カードを確認するチェック。

## 次段階：AIによる編集支援

1. テキスト資料の取り込みとカード候補の抽出。
2. テーマ候補の提示と、既存テーマへの重複・別名候補の提示。
3. 起承転結の記事下書き。各段落に根拠カードを紐付ける。
4. 時系列の矛盾、重複事例、根拠のない因果・数値の検出。
5. 文体・対象読者・長さの指定。

## 後続候補

- 出典を含むMarkdown、HTML、DOCXへの出力。
- チーム共有、レビュー、承認履歴。
- ローカルファイル監視やGit連携。
- 日報・週報を記事の素材として扱う際の要約重複検出。

AI支援機能の完了条件には、引用元との照合、人による編集、未確認情報を維持する評価を含める。モデルが文章を生成できることだけを完了条件にしない。
