# テーマ別ストーリー編集室

開発ログ、ナレッジ、日報、週報を小さな根拠付き記録として扱い、共通テーマで束ねて、起承転結の読みやすい記事へ編集するシステム。

## 目的

- 別々に書かれた記録から、テーマごとの経緯や学びを見つけやすくする。
- 記事の主張から元記録・成果物へ戻れるようにする。
- AIを使う場合も、事実・報告・推定・未確認を保ち、記録にない出来事や成果を作らない。
- 日報や週報を記事へ変換する際、同じ出来事の重複や数字の水増しを防ぐ。

## 編集の流れ

```text
記録を取り込む
  → 出来事・知見ごとのカードに分ける
  → テーマと根拠を確認する
  → 起承転結へ配置して記事を編集する
  → 元記録との対応と未確認事項を点検する
  → Markdownなどで書き出す
```

試作はAIによる自動分類・文章生成をまだ行わず、編集者がテーマと構成を確認する最小版。記録はブラウザのローカル保存領域に保管され、外部サービスへ送らない。
